# Haotian Tan — Academic Homepage

Public website: https://tan-ht.github.io/

This is a static academic website for GitHub Pages. It does not require a build step, a server, or third-party scripts.

## Updating the website

- Edit `index.html` to update the biography, education, publications, or research experience.
- Edit `styles.css` to update the presentation.
- Replace `haotian-tan.jpg` to update the portrait.
- Replace `Haotian_Tan_CV_CN.pdf` to update the downloadable Chinese CV.
- Keep `.nojekyll` at the repository root.

Publish from **Settings → Pages → Deploy from a branch → main → / (root)**.
After committing changes, GitHub Pages updates automatically.

Only public website assets are included; local CV source files and development credentials are excluded.
